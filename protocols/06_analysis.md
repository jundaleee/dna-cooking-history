# 프로토콜 6. 분석: 측정 점검에서 모델 평가까지

순서대로 하고, 앞 단계를 통과하지 못한 칸은 다음 단계에 넣지 않는다.

## 1. 원신호 Ct
기기가 기준 염료로 나누기 전의 형광(Multicomponent의 SYBR)으로 Ct를 다시 낸다. 기기 Ct와 함께 적고 차이가 큰 칸을 표시한다.

```bash
python -m rne.qpcr.raw_ct --export <판 .xls> --out raw_ct.csv
```

## 2. 대조 칸 판정(0단계)
재료를 뺀 대조 칸이 원신호에서 오르지 않는지 본다. 기본 기준: 신호 대 잡음 10 이상 또는 끝/처음 1.5배 이상이면 '오름'. 물만·믹스만·프라이머 없음 칸이 오르면 판 실패, 주형 없음 칸이 오르면 오염 또는 비특이 신호.

```bash
python -m rne.qpcr.controls --export <판 .xls> --layout <배치표.csv> --out <폴더>
```

대조 칸이 실패하면 온도·시간 판정을 보류한다(사전 고정한 행동).

## 3. 정상 증폭 점검
시료 곡선이 PCR의 물리적 제약을 지키는지 칸마다 본다: cycle당 증가 배율 2 이하, 기준 염료 일정, 산물이 있으면 멜트 봉우리. 이 조건을 지키는 가상 정상 곡선 4,000개로 학습한 마할라노비스 거리와 분할 등각 문턱(정상 곡선을 잘못 거부할 확률 5 % 이하)을 쓴다. 대조 칸은 평평한데 시료 곡선만 이상한 판을 잡는다.

```bash
python -m rne.qc.normal_range --xls <판 .xls> --layout <배치표.csv> --out <폴더> [--aggregate-only]
```

결과의 `synthetic_check`에서 가상 정상 곡선의 오거부율과, 기준 염료 상승·멜트 봉우리 없음·배율 초과를 넣었을 때의 검출률을 함께 보고한다.

## 4. 효율과 DDI
표준곡선 기울기로 구간별 효율을 내고(E = 10^(−1/s) − 1), DDI를 계산한다. 효율이 다르면 보정한 DDI도 낸다(`rne.qpcr.compute_ddi`).

## 5. 모델 평가
같은 조건의 반복이나 같은 추출 배치의 시료는 함께 빼서 평가한다. 세 평가 단위를 나란히 보고하고, 우연과의 비교는 라벨을 같은 배치 안에서만 섞는 순열 검정으로 한다.

```python
from rne.evaluate import compare_schemes
table = compare_schemes(model, X, y, condition=조건번호, batch=추출배치, n_perm=999)
```

R²의 신뢰 구간이 0(모든 시료를 평균으로 답한 성능)을 포함하면 유의성은 R²가 아니라 순열 p로 판단한다.

## 6. 정보량 보고
모델이 배운 정보는 조건 단위 교차검증의 예측과 참값 사이의 상호정보량으로 보고한다. KSG 추정량(`rne.design.information.ksg_bits`, 0.03비트 안팎은 0과 가르지 않음)과 정규 근사(`gaussian_bits`, 직선 관계를 가정해 낮게 잡을 수 있음)를 함께 적고, 측정이 가질 수 있는 최대(`exact_mi`)와 비교한다.
