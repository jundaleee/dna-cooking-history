# 프로토콜 3. qPCR 판

## 표적
닭 미토콘드리아 COI의 짧은 구간(104 bp)과 긴 구간(586 bp), 공통 역방향 프라이머. DDI = Ct(긴 구간) − Ct(짧은 구간).

| 이름 | 서열 (5'→3') | 산물 |
| --- | --- | --- |
| COI-100F | ACTCCTCTCCTTACCCGTCC | 104 bp |
| COI-586F | AGCCTTCTAATTCGCGCAGA | 586 bp |
| COI-R | GGATTGGGTCTCCTCCTCCA | 공통 역방향 |

설계: NCBI RefSeq NC_001323.1, Primer3, Primer-BLAST로 닭 특이성 확인. 586 bp는 많은 SYBR 시약의 권장 길이(200 bp 이하)보다 길어 두 구간의 효율이 다를 수 있으므로, 효율을 표준곡선으로 반드시 잰다(프로토콜 4).

## 반응(20 µL)
| 성분 | 부피 |
| --- | --- |
| 2X SYBR 마스터믹스 | 10 µL |
| 정방향 프라이머(10 µM) | 0.5 µL |
| 역방향 프라이머(10 µM) | 0.5 µL |
| 기준 염료(ROX) | 설명서의 기기별 권장량(아래 주의) |
| 물 | 나머지 |
| 주형 | 1 µL |

- **기준 염료 주의:** 마스터믹스에 ROX가 이미 들어 있는지, 기기(예: StepOnePlus)의 권장 농도가 얼마인지 설명서로 확인하고 기록한다. 기준 염료가 형광을 따라 오르면 기기 Ct가 크게 틀어질 수 있다
- 같은 시료의 두 구간은 같은 튜브의 주형을 쓴다

## 프로그램(예: StepOnePlus)
1. 95 °C 5분
2. 40 cycle: 95 °C 15초 → 60 °C 30초 → 72 °C 30초(측정)
3. 멜트: 95 °C 15초 → 60 °C 1분 → 95 °C까지 올리며 측정

Passive reference 설정(ROX 사용 여부)을 기록한다.

## 판 배치
`python -m rne.design.layout --temps ... --times ... --reps ... --out plate_layout.csv`로 만든다(예: `templates/plate96_layout_example.csv`).
- 같은 시료의 두 구간은 **같은 판의 이웃 칸**(홀수 열 짧은 구간, 짝수 열 긴 구간). 판이 다르면 판 사이 차이가 DDI에 그대로 들어간다
- 시료 위치는 조건과 무관하게 무작위. 줄·열이 온도·시간을 설명하는 비율(η²) 0.02 이하. 위치가 조건 순서와 같으면 효과가 없는 경우에도 '효과 있음'이 자주 나온다
- **재료를 하나씩 뺀 대조 칸**: 주형 없음(NTC) 8, 프라이머 없음 4(주형은 시료), 믹스만 2, 물만 2. 실패했을 때 원인의 범위를 칸 단위로 좁힌다

## 분주
1. 배치표의 칸 순서대로 주형을 넣는다(A줄 1→12열, B줄 …). 시료 튜브를 조건 순서로 늘어놓고 차례로 넣지 않는다
2. 칸마다 팁을 바꾼다
3. 주형 없음·물 칸은 마지막에 넣고, 그 전까지 물 튜브를 닫아 둔다
4. 반응 뒤 대조 칸 몇 개의 남은 부피를 재서 증발 여부를 기록한다

## 판 돌리기 전 점검표

| 단계 | 확인할 것 | 통과 기준 |
| --- | --- | --- |
| 시약 | 설명서의 기준 염료 포함 여부와 기기별 권장량, 로트, 보관 온도, 동결해동 횟수 | 설명서와 일치, 기록 |
| 기기 | 염료 설정, 기준 염료 사용 여부, 판·필름 호환 | 기록 |
| 예비 판 | 큰 판 전에 12–20칸(프로토콜 4) | 프로토콜 4의 R1–R5 |
| 판 배치 | 두 구간 이웃 칸, 시료 위치 무작위 | 줄·열의 η² 0.02 이하 |
| 분석 | 기기 Ct 대신 원신호 Ct, 판정 규칙과 코드의 해시값을 결과 전에 기록 | 커밋 시각(프로토콜 5) |
| 뒤처리 | 반응 뒤 남은 부피, 원자료 파일과 해시값 보관 | 기록 |
