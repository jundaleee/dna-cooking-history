# 프로토콜 2. DNA 추출과 품질 기록

## 목적
추출 배치의 차이가 가열 효과처럼 보이지 않게 한다. 추출 배치가 조건과 겹치면(예: 일부 온도만 다시 추출) 농도 차가 지표에 그대로 들어가고, 평가에서도 배치가 온도를 대신 설명한다.

## 원칙
- **모든 조건을 한 추출 배치로** 추출한다: 같은 날, 같은 방법, 같은 사람, 같은 시약 로트
- 한 배치로 못 하면 배치마다 모든 조건이 고르게 들어가게 섞고, 배치 번호를 시료마다 기록한다(나중에 배치 단위 평가에 쓴다)
- 추출 순서를 조건 순서와 무관하게 무작위로 한다
- 추출 방법(키트 이름, 시료 양, 용출 부피)을 기록한다

## 품질 기록
- 분광 측정(예: NanoDrop): 농도, 260/280, 260/230을 시료마다 기록한다. 기기 내보내기 파일을 그대로 보관한다(열 이름이 바뀌어 있지 않은지 확인)
- 배치별 농도 분포를 비교한다. 농도가 배치 사이에 4–8배 다르고 두 구간의 효율이 다르면, 손상과 무관하게 DDI가 0.2 cycle 안팎 움직일 수 있다(그 영향은 `rne.design.error_budget`로 비트 단위로 계산한다)
- 표준곡선용으로 비가열 DNA의 원액·1/10·1/100 희석을 만든다(프로토콜 4)

## 보관
추출 DNA의 보관 온도와 동결해동 횟수를 기록한다. 원자료 파일은 받은 즉시 지문(sha256)을 남긴다(프로토콜 5).
